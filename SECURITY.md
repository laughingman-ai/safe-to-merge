# Security

This repo is a demo of gates for AI coding agents, so a way past them is a finding we want.

**To report one privately**, use GitHub's [private vulnerability reporting](https://github.com/laughingman-ai/safe-to-merge/security/advisories/new). Please don't open a public issue for anything that exposes the CI reviewer's API key or gets a change onto `main` without the owner's approval.

**Known limits** are listed in the README under "Limits, stated plainly". A bypass of the in-session hooks alone is useful to hear about, but the hooks are a filter, not the boundary. The boundary is CI, the rules on `main`, and the owner's approval.

We aim to reply within two business days.
